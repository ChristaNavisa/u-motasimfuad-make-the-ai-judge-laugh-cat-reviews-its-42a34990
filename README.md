One funny single-line one-star review from a house cat about its human, written by a small TypeScript program for the [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) bounty on make.fun.

Run `node main.ts`; it writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
